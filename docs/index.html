Tu lista de compras,

SuperLista es una app web minimalista para armar tu lista, ponerle precio y cantidad a cada producto y saber en todo momento cuánto llevas y cuánto te queda.

// características

Lo justo para hacer la compra sin cuentas mentales

Sin registro, sin apps que instalar. Abrís el navegador y listo.

Lista con checkbox

Agregá productos y marcá cada uno cuando lo pongas en el carrito. Los comprados bajan al final de la lista.

Precio y cantidad por producto

Al marcar un producto le ponés precio unitario y cantidad. SuperLista calcula el subtotal y el total al instante.

Presupuesto con barra

Fijás un presupuesto y una barra te muestra cuánto llevas. Te avisa cuánto te resta o cuánto te pasaste.

Historial de compras

Al terminar guardás la compra con un nombre. Queda un snapshot con productos, total y presupuesto de ese día.

Comparador de precio por unidad

¿12 rollos de 200 hojas o 4 de 500? Ingresá precio y cantidad de cada opción y SuperLista te dice cuál sale más barata por unidad.

SQLite + migraciones

Flask, SQLAlchemy y Flask-Migrate/Alembic. Sin servidor de base de datos: un archivo SQLite y listo.

// instalación

Corriendo en local en 3 pasos

Necesitás Python 3.10 o superior. La base de datos es un archivo SQLite que se crea con las migraciones.

01

Clona el repositorio

Descarga SuperLista desde GitHub.

bash clonar
git clone https://github.com/4drian0rtiz/SuperList.git
cd SuperList
02

Crea el entorno virtual e instala dependencias

Un virtualenv aislado con las dependencias de requirements.txt.

bash terminal
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

En Windows el activador es venv\Scripts\activate.

03

Prepara la base y levanta el servidor

flask db upgrade aplica las migraciones y crea instance/superlist.db. run.py levanta el servidor de desarrollo.

bash terminal
export FLASK_APP=run.py
flask db upgrade
python run.py

Abre http://localhost:5002. Copia .env.example a .env para ajustar el puerto o la base.

// uso

Cómo se usa

Tres pantallas, accesibles desde el menú lateral.

Pantalla Para qué sirve
/ Armar la lista, poner precios y fijar el presupuesto.
/comparador Comparar el precio real por unidad de varias presentaciones.
/history Ver las compras guardadas con su total y presupuesto.

Una compra, de principio a fin

1

Añade productos

Escribe el nombre y pulsa Añadir. Repite para cada producto de la lista.

2

Fija el presupuesto

Abre el panel de presupuesto e ingresa el monto. La barra empieza a llenarse a medida que cargas precios.

3

Marca y pon precio

Cuando pones un producto en el carrito lo marcas, le pones cantidad y precio unitario. El subtotal aparece al lado.

4

Vigila el total

El pie de la lista muestra el total y si te resta dinero o te pasaste del presupuesto.

5

Guarda la compra

Pon un nombre (ej: Semanal) y guarda. Los productos comprados pasan al historial y la lista queda limpia para la próxima.

// comparador

Comparador de precio por unidad

El producto más barato no siempre es el que cuesta menos.

Ingresa una unidad de comparación (hojas, ml, g, unidad) y luego, por cada opción, su precio y la cantidad total que trae. SuperLista divide precio entre cantidad y ordena de más barato a más caro por unidad.

En la cantidad puedes usar * para multiplicar presentaciones sin sacar la cuenta a mano.

texto ejemplo
# Unidad: hojas
Opción 1 — $85.00 · 12 * 200 # = 2400 hojas → $0.0354/hoja
Opción 2 — $40.00 · 4 * 500 # = 2000 hojas → $0.0200/hoja

12 rollos de 200 hojas = 2400 hojas. Si cuesta $85, el precio por hoja es $0.0354.

// configuración

Variables de entorno

Todo opcional en desarrollo. Copia .env.example a .env y ajusta lo que necesites.

Variable Descripción
FLASK_ENV development | testing | production. Define el modo y la configuración activa.
SECRET_KEY Clave de sesión de Flask. Obligatoria en production; en desarrollo se usa un valor por defecto inseguro.
DATABASE_URL URL de la base. Por defecto sqlite:///instance/superlist.db.
PORT Puerto del servidor de desarrollo (run.py). Por defecto 5002.

En production el arranque falla si SECRET_KEY sigue siendo el valor por defecto. Define uno propio antes de desplegar.

Importar historial anterior

Si vienes de la versión con history.json, flask import-history carga esas compras a SQLite. Es idempotente: omite las que ya existen.

bash terminal
flask import-history --path history.json
